## 🛠️ Troubleshooting Common Issues

Most users don't encounter problems, but here are solutions to common questions:

### The application won't start
- **Solution:** Make sure you've completed the installation fully. Try restarting your computer, then launch Ghostfolio again.
- **Fallback:** Re-download the installer from the link above and run it again.

### Market data isn't updating
- **Solution:** Check your internet connection. Ghostfolio needs to be online to fetch current prices.
- **Fallback:** Close and reopen the application. Data will sync automatically.

### I can't find a specific asset
- **Solution:** Try using the ticker symbol instead of the full name. For example, search "VTI" instead of "Vanguard Total Stock Market ETF."
- **Fallback:** Ensure you're using the correct asset type. Some assets might be classified differently than you expect.

### The dashboard looks broken or blank
- **Solution:** Clear the application's cache. Look for a "Clear Cache" option in the settings menu.
- **Fallback:** Uninstall and reinstall the application. Your saved data will be preserved in most cases.

### I forgot the value of an investment I added
- **Solution:** Ghostfolio stores historical data. Navigate to the asset's detail page and view its price history.
